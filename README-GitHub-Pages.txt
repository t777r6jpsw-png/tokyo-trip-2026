東京六日手帖｜GitHub Pages 上傳說明

1. 解壓縮本 ZIP。
2. 在 GitHub 建立一個 Repository。
3. 將解壓縮後的所有檔案與 assets 資料夾上傳到 Repository 根目錄。
   請確認 index.html 位於最外層，不要再包在另一層資料夾內。
4. 進入 Repository 的 Settings → Pages。
5. Source 選 Deploy from a branch，Branch 選 main，Folder 選 /(root)，再按 Save。
6. 等待數分鐘後，即可使用 https://你的帳號.github.io/Repository名稱/ 開啟。

注意：
- 網站不需要 ChatGPT 登入。
- 網站的新增、編輯與刪除內容儲存在目前瀏覽器；不同手機或電腦不會自動同步。
- 可使用網站內的「匯出備份／匯入備份」在裝置間搬移行程。
